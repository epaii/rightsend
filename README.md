# 右键快传 RightSend

> 数据同步，局域网速度更快。

右键共享文件，弹出二维码，手机扫码就能查看、下载，也支持手机往电脑上传。局域网直传，不消耗手机流量。

**官网：** https://epaii.github.io/rightsend/

| 平台 | 安装包 |

## 三步就能用

1. **电脑右键** —— 选中文件或文件夹，右键选择快传。
2. **弹出二维码** —— 手机上扫码。
3. **手机查看或下载** —— 浏览器直接打开，微信里也能保存、转发；还可反向上传文件到电脑。

## 功能

- 局域网直传，跑满 WiFi 速度，不走移动网络
- 手机浏览器直接打开、下载，微信里可保存转发，视频边下边播
- 目录云盘式浏览：搜索、排序、在线预览、原图下载
- 支持手机上传，可开关「允许手机上传」
- Windows 资源管理器 / macOS Finder 右键菜单集成
- 免安装 App，手机端零安装
