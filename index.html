常见问题FAQ

你可能想问的Questions you might have

必须在同一个 WiFi 吗？Do we need the same WiFi?

局域网传文件时需要。好处是速度快、不耗流量、不用上传云端；异地传输可用外网二维码。For LAN transfers, yes. The payoff is speed, zero mobile data and no cloud upload; use a remote QR code when apart.

手机真的不用装 App？Do I need an app on my phone?

不用。扫码后用手机浏览器就能下载；在微信里打开也能保存和转发。No. Scan and download in your mobile browser, or open in WeChat to save and share.

安全吗？文件会上传到哪？Is it safe? Where do files go?

不会上云，文件只在你的设备之间直连传输。访问链接带随机 token，单文件链接一次一换。Nowhere in the cloud — files move directly between your devices. Links carry random tokens; single-file links change every time.

支持哪些系统？Which systems are supported?

电脑端支持 Windows 和 macOS；手机端不限系统，能扫码、能上网就行。Windows and macOS on desktop; any phone that can scan a QR code and open a browser.
